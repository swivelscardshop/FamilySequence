# Pre-release review — not legal clearance

The earlier family-game build was inspired directly by a named commercial board game. This release replaces that branding and board, standard-card theme, free corners, path length, win target and overlap rule. It independently implements its code, instructions and CSS visual assets. No official logos, rulebook text, product images, scanned card faces or personal photographs are included.

Remaining review: clear the working title and icon; have an IP attorney evaluate the final game and any relevant rights, including patents and trade dress. Similar mechanics alone do not settle all legal questions. Changes are intended to reduce copying concerns, not to establish a legal safe harbor. Check deployment regions and store requirements before public release.

Retained third-party software: React / React DOM (MIT), esbuild (MIT) as pinned in the package lock; bundled browser dependencies include their esbuild license notices in public/app.js.LEGAL.txt. Font CSS optionally requests Noto Sans TC from Google Fonts; retain its applicable licensing or replace with system fonts. This review note does not replace those licenses or professional review.
